ใช้งาน starter นี้อย่างไร

โฟลเดอร์นี้มีกติกา skill agent hook script แม่แบบ และ dashboard ครบแล้ว แต่ยังไม่มีเนื้อหา งานของเราคือสั่ง agent ให้อ่านเอกสาร แล้วดูความรู้สะสมขึ้นใน Obsidian และ dashboard

1 · ติดตั้ง

git clone https://github.com/Migchw/wiki-research-starter my-research-wiki
cd my-research-wiki
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
cd dashboard && npm install && npm run dev

ชิ้น · วิธีเรียกทำอะไรได้ไฟล์อะไรไปโผล่ใน dashboardทำไมต้องมี

<คำถาม>		ตอบจาก vault เท่านั้น ทุกข้อมีลิงก์และที่มา ถ้าไม่มีให้บอกว่าไม่มีคำตอบในแชท · articles/<slug>.md ถ้าเลือกเก็บการ์ดบทความ (ถ้าเก็บ)ถามจากสิ่งที่อ่านแล้ว ไม่ใช่จากความจำของโมเดล

4 · script

งานที่ต้องอ่าน ตีความ หรือเขียน ให้ agent ทำ ส่วนงานที่ต้องนับ คำนวณ ตรวจ หรือแปลงไฟล์ ให้ script ทำ เพราะได้ผลเหมือนเดิมทุกครั้งและไม่เสีย token

ไฟล์ทำอะไรรันอย่างไร
wiki_lint.pyตรวจ frontmatter ลิงก์ pre-registration และ trial ซ้ำpython scripts/wiki_lint.py
source_to_text.pyPDF / HTML ของ SEC → ข้อความที่มีป้ายหน้าและ Itemskill ingest-source เรียกเอง
extract_pdf.pyPDF ของ paper → ข้อความที่มีป้ายหน้าpython scripts/extract_pdf.py --help
crop_figure.pyตัดรูปกราฟจากหน้า PDF ไปที่ assets/ (ไม่เข้า git)python scripts/crop_figure.py <pdf> <page> <out.png>
validate_facts.pyตรวจว่าตัวเลขใน facts/*.json อยู่บนหน้าที่อ้างจริงและบวกลบลงตัวpython scripts/validate_facts.py --help
backtest_momentum.pybacktest momentum 12-1 / 12-7 บน SET100 แล้วเขียน experimentpython scripts/backtest_momentum.py --hypothesis H-001 --lookback 12-7 --dry-run
set100.txtรายชื่อหุ้น SET100 ที่ backtest ใช้แก้รายชื่อได้ตามต้องการ
sync_skills.pyสร้าง .agents/skills/ จาก .claude/ ให้ agent อื่นใช้python scripts/sync_skills.py
paper_feed.pyดึง paper ใหม่มาเป็นไอเดีย (ไม่บังคับ)python scripts/paper_feed.py --help

5 · dashboard ทำงานอย่างไร

npm run dev รัน dashboard/scripts/build-index.mjs ก่อน สคริปต์นี้อ่าน frontmatter ของ papers/ sources/ articles/ hypotheses/ experiments/ .claude/skills/ และ atoms/ แล้วเขียน dashboard/public/index.json หน้าเว็บอ่านจากไฟล์นั้นอย่างเดียว ไม่แก้ไฟล์ใน vault

หลัง ingest เอกสารใหม่ ให้รัน npm run index แล้ว refresh หน้า ตอน vault ยังว่างจะเห็นแค่การ์ดสกิล ซึ่งเป็นสภาพปกติ

มีมุมมอง 3 แบบ คือ การ์ด รายการ และแผนที่ (จาก atoms/) กดการ์ดแล้วรายละเอียดเลื่อนออกมาจากด้านขวา ปุ่มคัดลอกคำสั่งในการ์ดสกิลเอาไปวางใน agent การแก้ทุกอย่างจึงผ่าน skill lint และ hook เสมอ

6 · ใช้กับ agent อื่น

AGENTS.md คือกติกาที่ agent ทุกตัวอ่าน ส่วน .agents/skills/ คือ skill ชุดเดียวกันสำหรับ agent ที่ไม่ใช่ Claude Code ให้แก้ skill ที่ .claude/ เท่านั้น แล้วรัน python scripts/sync_skills.py
