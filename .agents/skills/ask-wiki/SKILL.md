# /ask-wiki

## ขั้นตอน
1. หาโน้ตที่เกี่ยวข้อง: เริ่มจาก `companies/` หรือ `concepts/` แล้วตามลิงก์ไป `sources/` และ `papers/`
   ใช้ Grep ค้นคำสำคัญ ห้ามตอบจากความจำของโมเดล
2. ตอบเป็นข้อๆ ทุกข้อลงท้ายด้วย `([[source-id]] p. N)` หรือ `Item 7` หรือ `[mm:ss]` ตามที่ source note อ้าง
3. แยกให้เห็นว่าข้อไหนเป็น fact ข้อไหนเป็นคำพูดหรือคาดการณ์ของบริษัท
4. ถ้าเอกสารสองชิ้นพูดไม่ตรงกัน ให้แสดงทั้งสองฝั่งพร้อมวันที่เผยแพร่ ห้ามเลือกฝั่งเดียวเอง
5. ส่วนที่ vault ไม่มี ให้เขียนหัวข้อ "vault ยังไม่มี" แล้วบอกว่าต้อง ingest เอกสารอะไร ห้ามเติมจากความรู้ทั่วไป
6. ถ้าต้องคำนวณ (เช่น % การเติบโต) ให้รันสคริปต์ Python กับตัวเลขที่คัดจาก source note แล้วแสดงคำสั่งที่ใช้
7. ถามผู้ใช้ว่าจะเก็บเป็น **คำตอบที่เก็บไว้** ที่ `articles/<slug>.md` (`basis: vault`, `status: draft`, tag `ask-wiki`) ไหม ถ้าเก็บ รัน lint ให้ผ่าน
   ไฟล์นี้คือคำตอบของคำถามเดียว ไม่ใช่บทความอธิบายเอกสาร (บทความอธิบายเขียนโดย `/ingest-source` และ `/ingest-paper` จากต้นฉบับ)
